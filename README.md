# ST606 MSc Thesis

## Predicting Net Ecosystem Exchange Using Environmental Time-Series Data

This repository contains the analysis, visualisations, and modelling workflow for my ST606 MSc thesis project.

### Project Components
- Data preprocessing
- Exploratory data analysis
- Time-series analysis
- Regression modelling
- Machine learning models

### Repository Structure
- `scripts/` : analysis scripts and R Markdown files
- `plots/` : generated figures and visualisations
- `presentation/` : thesis presentation materials
